# About this site

This site describes how Gavin Dhondt works: his tools, setup and working preferences. It exists so that an AI agent
working with him can read it once and start with the right defaults, instead of rediscovering them in every session.

## How to read it

- Start at `/llms.txt`. It lists every document with a one-line summary.
- A path ending in `/` lists its contents. A path ending in `.md` is a document.
- `/llms-full.txt` returns every document in one response.
- Everything here is public and read-only.

## What to expect

The documents state preferences and, where it matters, the reason behind them. When a preference conflicts with a
project's own instructions, the project's instructions win for that project.
